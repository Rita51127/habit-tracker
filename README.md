# ⭐ Habit Tracker App

A simple beginner-friendly React application that helps users track daily habits, stay consistent, and visualize progress.

---

## 🚀 Features

- Add daily habits (Study, Drink Water, Exercise, etc.)
- Automatic emojis for habits 🌟💧📚🏃‍♀️
- Mark habits as completed by clicking
- Delete unwanted habits
- Shows completed progress count
- Progress bar to visualize growth
- Empty state message when no habits exist

---

## ⚙️ Setup Instructions

```bash
git clone <your-repo-link>
cd habit-tracker
npm install
npm run dev
